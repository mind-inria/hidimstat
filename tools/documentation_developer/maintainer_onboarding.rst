Onboarding For New Maintainers
==============================
This guide is here to welcome new maintainers, and list all necessary access for the library.

Accounts Overview And Associated Rights
---------------------------------------
We provide an overview of accounts and tools necessary to help maintaining the library:

* Hidimstat's main `GitHub repository <https://github.com/mind-inria/hidimstat>`_:
  obvious, but central to the project. The rights are managed per user.
  Make sure an access level of ``maintain`` or ``admin`` is given.
* Hidimstat's `documentation GitHub repository <https://github.com/hidimstat/hidimstat.github.io>`_:
  this is where all the documentation builds, generated by the Continuous Integration (CI) pipeline,
  are uploaded for both the stable releases, or dev builds from the ``main`` branch of the repository.
  The rights are managed similarly as the main repository.
* `PyPi <https://pypi.org/>`_: the Python Package Index is where the release package is uploaded,
  so all users can directly install them with the python package manager ``pip``.
  The rights are managed per user.
  Make sure an access level of ``maintain`` or ``admin`` is given.
* `TestPyPi <https://test.pypi.org/>`_: similar to PyPi, it provides a separate, dedicated testing
  environment for PyPi. The rights are managed similarly as for PyPi, but require an independent setting
  from PyPi.
* `CircleCI <https://circleci.com/>`_: as one of the CI tools, it executes the documentation build at the end of the pipeline,
  and uploads the output files on the documentation repository.
  A new maintainer should have a direct access to CircleCI by authentifying
  themselves on the website with their GitHub account. The organization ``mind-inria`` in CircleCI uses the
  `GitHub OAuth app integration <https://circleci.com/docs/guides/getting-started/invite-your-team/#join-via-github>`_,
  which means all CircleCI role and permission settings are inherited from GitHub.
  No additional parametrization is required.
* `CodeCov <https://about.codecov.io/>`_: this tool creates easy-to-read test reports to assess the code coverage of tests.
  It is a necessary tool to ensure that all functionalities are tested either through unit tests,
  or functional tests. The parameters are set at the organization level, which is configured via the GitHub App.
  New members should be added by another admin, with the according rights.
